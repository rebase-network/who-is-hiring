General

我们正在寻找一位 **Blockchain Engineer**，加入团队一起做真正落地的数字资产和区块链产品。 这个职位不是简单调用 API 或搭建 Web3 Demo。你会参与区块链系统从 **0 到 Production** 的整个过程，包括 Blockchain Infrastructure、Smart Contracts、Wallet、交易系统、On-chain Data，以及不同 Blockchain Networks 的 Integration。 我们希望你真正理解 Blockchain 的工作原理，遇到问题能够自己研究、找到答案并完成实现。相比会多少 Framework，我们更看重你**实际做过什么**、工程能力以及解决问题的能力。 如果你有 **Bitcoin、Ethereum、EVM、L2、Smart Contracts、Wallet、Custody、DeFi、Stablecoins 或 Blockchain Infrastructure** 经验，会比较有帮助。 技术栈方面，熟悉 **Python、Go、Rust、TypeScript 或 Solidity** 中的一种或多种即可。不要求你什么都会，也不要求金融背景。 你会和 Engineering、Product 以及金融业务团队一起工作，解决真实的数字资产问题。如果你喜欢 Blockchain、Crypto，并且喜欢把东西真正做出来，欢迎联系我们。 **Full-time｜Remote / Hybrid｜HKT (UTC+8)** 每天约 3–4 小时与团队重叠。 **薪酬：HKD 100,000–150,000 / 月 Base + Bonus / Equity**，具体根据经验确定。 Telegram：**@silian0x** 请发送 **CV、LinkedIn 或 GitHub**。如果有自己做过的 Blockchain / Web3 项目，也欢迎一起发过来。
