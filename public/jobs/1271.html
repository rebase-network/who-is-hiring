LOOTRUSH(S) / 全职招聘

我们不是在招聘某一个框架的开发者。 我们在寻找真正懂工程能力的人。 Lootrush(s) 正在寻找一名 区块链 & 后端工程师，负责构建区块链产品背后的核心技术系统——从后端架构、数据基础设施，到智能合约交互、链上交易处理。 如果你能够从： 架构 → 开发 → 上线 → 稳定运行 → 性能优化 完整负责一个系统，那么继续看下去。 ## 🧬 你会处在哪个位置？ 你会同时面对两个世界。 ### OFF-CHAIN｜链下 API → 服务架构 → 数据库 → 消息队列 → 缓存 → 身份认证 → 业务逻辑 → 云基础设施 ### ON-CHAIN｜链上 Wallet → Transaction → RPC → Smart Contract → Events → Logs → Tokens → Confirmations 你的任务： 让链上和链下真正稳定地连接起来。

你真正要做的事情

- 设计和开发后端服务及分布式系统 - 构建高性能 API - 开发区块链交易基础设施 - 对接智能合约 - 实现链上 / 链下数据同步 - 处理 Blockchain Events / Logs - 构建钱包、Token 相关服务 - 开发区块链数据索引和数据处理流程 - 交易监控、失败重试和异常恢复 - 数据库架构设计与性能优化 - 身份认证与安全体系 - 高并发、异步任务及消息处理 - 生产环境监控、稳定性与故障排查

你也会遇到真正有意思的问题

为什么交易失败？ 为什么 Event 没有正常到达？ 为什么数据库状态和链上状态不一致？ RPC Provider 挂了怎么办？ 如果同时进来 10,000 笔交易，系统还能不能正常运行？ 这才是我们认为真正有价值的工程工作。

后端能力

我们不限制后端语言。 如果你的主要技术栈是： Go / Java / Python / Rust / C# / Node.js / C++ / PHP / 其他 都可以。 我们更看重你是否真正理解后端工程。 你应该熟悉： → API Architecture → Microservices / Modular Architecture → Concurrency & Async Processing → Database Design → Caching → Message Queue → Distributed Systems → Authentication & Authorization → Fault Tolerance → Observability → Performance Optimization → Security → Testing 语言只是工具。 工程基础才是核心。

区块链能力

希望你至少有一个主流区块链生态的实际开发经验，优先考虑 EVM 生态。 包括但不限于： Ethereum / EVM Solidity ethers.js / viem / Web3 Libraries RPC Providers Smart Contract Integration Transactions & Gas Events & Logs Wallets & Signatures Token Standards Blockchain Indexing 我们更看重你是否真正理解区块链系统在生产环境中的运行方式，而不仅仅是知道几个 Web3 关键词。
