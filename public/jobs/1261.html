职位概述

StraitsX是一家总部在新加坡的数字资产基础设施公司，主要做数字资产、支付和区块链相关的基础设施服务。现在团队在扩张，想找一位比较资深的 Blockchain Engineer，主要负责 Smart Contract 和 Token 这块。

职责描述

  • 主要负责 Solidity Smart Contract 的开发，包括设计、开发、测试和部署。
  • 负责 ERC-20 Token 以及相关链上功能，涉及 Token 的 Mint、Burn、Transfer、权限控制等。
  • 做好合约测试，包括 Unit Test、Integration Test、Fuzz Test 等，保证上线前的代码质量。
  • 参与 Code Review，及时发现合约里的安全问题、逻辑问题以及 Gas 使用问题。
  • 配合 Security Team 和第三方审计公司做 Smart Contract Audit，并负责后续问题修复。
  • 负责 Ethereum / EVM 链上的合约部署、Verification 以及上线后的维护。
  • 和 Backend、Product、Infrastructure 等团队一起，把链上合约和链下系统真正跑通。
  • 参与技术方案讨论。遇到链上实际问题时，需要能够自己定位和解决，而不是只负责写代码。

任职要求

  • 4年以上软件开发经验，有比较扎实的 Blockchain 开发经验。 Solidity比较熟，有真正上线过的 Smart Contract 项目。最好是自己从设计到上线都参与过。 对 Ethereum / EVM 比较熟，知道 Transaction、Gas、Storage、Event、Log 这些底层机制是怎么工作的。 熟悉 ERC-20 等常见 Token 标准。 熟悉 Foundry 或 Hardhat，能够自己写测试和部署脚本。 对 Smart Contract Security 有基本判断能力，知道 Reentrancy、Access Control、Signature Replay、Oracle Manipulation 等常见问题。 有正常的软件工程习惯，熟悉 Git、Code Review、CI/CD。 能够独立推进工作。因为团队是 Remote / Hybrid 模式，所以沟通和自我管理能力也比较重要。 有以下经验会比较加分： 我们比较看重的是实际项目经验。 如果之前只是自己写过一些 Token 合约或者做过课程项目，可能不是特别匹配。最好是之前有真正上线的项目，经历过测试、审计、部署以及上线后的各种问题，能够自己把 Smart Contract 这一块撑起来。) 做过 Stablecoin、Tokenization、Payments 或 Digital Asset 项目； 做过交易所、钱包、托管、支付或 Fintech 相关项目； 有 Smart Contract Audit 或安全审计经验； 熟悉 Foundry、Slither、Echidna 等工具； 做过 Multi-Sig、Access Control、Contract Upgrade； 对 Blockchain RPC、Indexer、On-chain Data 有了解； 会 TypeScript、Go 或 Python。
