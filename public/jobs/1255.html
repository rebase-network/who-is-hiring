General

# GRVT 招聘｜Smart Contract Engineer / Protocol Engineer **工作地点：新加坡 / Remote Friendly** **时区：优先 GMT+8** **薪资：S$15,000–18,000 / 月，具体根据经验而定** [[GVRT](https://gvrt.io/)] GRVT 目前招聘两位核心工程师： 我们希望找到真正做过项目、能够独立解决问题的工程师，一起参与 GRVT 核心协议和系统的设计与开发。 这不是单纯按照需求写代码的岗位。你会参与技术方案、架构设计、开发、测试以及上线后的维护。 --- - **Smart Contract Engineer（智能合约工程师）** - **Protocol Engineer（协议工程师）**

Smart Contract Engineer

主要负责协议的链上部分，包括 Solidity 智能合约开发、合约架构、安全、测试和上线后的维护。

工作内容

- 负责 Solidity Smart Contract 的设计、开发和维护 - 参与合约架构、接口以及模块设计 - 编写测试，进行 Fuzzing / Edge Case 测试 - 关注 Gas、执行效率以及合约可维护性 - 负责合约部署、升级及后续维护 - 参与第三方安全审计，并跟进 Audit Findings - 分析和解决线上合约问题 - 与 Protocol Engineer 一起完成协议功能的设计和实现

我们希望你具备

**加分项：** --- - 扎实的 Solidity 开发经验 - 熟悉 Ethereum / EVM - 有主网 Smart Contract 开发和上线经验 - 对 Smart Contract Security 有较好的理解 - 熟悉 Foundry、Hardhat 或类似开发工具 - 具备良好的软件工程基础 - 能够理解协议设计，并将其落地为可靠、清晰的代码 - Rust / Go / TypeScript - DeFi 项目经验 - L2 / EVM 多链经验 - Smart Contract Audit 经验 - 开源 Blockchain 项目经验

Protocol Engineer

主要负责协议整体的设计和开发。 除了 Smart Contract 之外，还会涉及 Off-chain Service、Backend、Infrastructure，以及链上链下之间的数据和交易流程。 你会和 Smart Contract Engineer 一起工作，并参与协议整体架构和技术方案的制定。

工作内容

- 参与 Protocol Architecture 的设计和实现 - 负责链上、链下系统的整体设计 - 开发 Protocol Backend / Services - 设计和维护数据、交易以及系统流程 - 处理系统稳定性、性能和扩展性问题 - 参与技术方案和架构决策 - 负责不同 Protocol Components 之间的整合 - 与 Smart Contract Engineer 一起推进协议落地

我们希望你具备

**加分项：** --- - 扎实的软件工程经验 - 熟悉 Rust、Go 或其他 Backend / Systems Language - 对 Blockchain Architecture 有较好的理解 - 熟悉 Ethereum / EVM 和 Smart Contract - 有 Distributed Systems 或系统架构经验 - 能够独立分析和解决复杂技术问题 - 有 Production System 的开发和维护经验 - DeFi 项目经验 - L2 / Rollup / Bridge 等 Blockchain Infrastructure 经验 - Ethereum Internals / EVM 相关经验 - Protocol Economics / Mechanism Design - 开源 Blockchain 项目经验

我们比较看重

我们不会只看你的简历上写了多少技术栈。 如果你真正做过 Smart Contract、Protocol、Blockchain Infrastructure 或其他 Production System，并且能够清楚讲明白自己负责什么、为什么这样设计、遇到什么问题以及最后怎么解决，这对我们来说更重要。 不需要满足 JD 上的每一项要求。 如果你有比较强的工程能力，并且愿意深入解决问题、承担技术责任，我们都欢迎交流。 ---
