职责描述

  • 1。参与核心系统全生命周期管理，从架构设计、代码实现到部署监控与持续迭代，覆盖 Indexer、API、后台任务、数据管道及内部服务
  • 2。负责云基础设施的搭建与运维，在 AWS 或 GCP 上管理容器、队列、缓存、数据库，并通过 CI/CD、日志、监控、告警和成本控制保障生产环境稳定运行
  • 3。构建低延迟、高可用的实时数据推送系统，通过 WebSocket 向客户端推送价格、交易、看板等数据，并在多条 EVM 链扩展中协调 Indexer 与 RPC 基础设施，确保跨链状态一致性与容错机制
  • 4。设计并维护驱动 AI Agent 的后端基础设施，支持开发者工具、链上推理工作流和内部自动化，涵盖 LLM API 集成、Tool Calling 循环、Skill 执行、日志监控与可靠性保障
  • 5。端到端交付产品功能 —— 从链上事件捕捉、Indexer 数据处理、API 暴露，到 React / Next.js 前端界面落地，覆盖交易、发射、代币看板、钱包连接等完整链路
  • 6。深度参与 AI Agent 生态建设，不仅使用 AI 编程工具，更参与开发、调优和优化 Agent Skill，服务于外部开发者与内部工程流程

任职要求

  • 1。中文书面与口语流利（必须），英文书面与口语流利（加分项，优先考虑） 2。拥有扎实的生产级全栈开发经验，熟练使用 TypeScript / Node.js / React / Next.js，掌握 Rust 或 Go 者优先 3。深入掌握 PostgreSQL、Redis、消息队列、后台任务、缓存策略与高并发系统设计，能构建正确、快速、稳定的高负载系统 4。具备 AWS 或 GCP 生产环境实操经验，熟悉 Docker、Kubernetes 等容器编排方案，以及部署、扩容、CI/CD、日志、监控、告警和成本优化 5。具有链上数据处理的生产系统经验，包括 Indexer、事件监听、RPC 协调、交易提交等模块 6。能清晰理解并做出技术取舍：eth_getLogs 分页、Subgraph 查询、第三方 API、自建 Indexer 在不同场景下的优劣与选型； 7。具备 Web3 前端开发经验，熟悉 wagmi、viem、ethers，能处理钱包连接、交易签名、合约交互、切链、Pending、Revert 等复杂场景 8。日常使用 AI 编程工具（如 Cursor、Claude Code、Codex），并能清晰阐述其在开发流程中的实际应用 9。具备 LLM API、Tool Calling、Agent 工作流及 AI 系统生产化经验 10。默认关注安全与边界场景：限流、输入校验、鉴权、钱包交互安全、滥用防护、交易 Pending / Revert / 切链等 1。有智能合约开发经验，能阅读、编写或审计 Solidity 合约； 2。深入理解 EVM 底层机制，能安全构建与智能合约交互的后端系统； 3。有 BNB Chain、Base、Solana 等高吞吐公链的生产级 Indexer 开发经验； 4。有生产级 Agentic AI 系统开发经验，而非仅限 Prompt Engineering； 5。有高并发、高可用、低延迟系统设计经验； 6。有丰富的前端性能优化经验，能构建流畅、响应迅速的 Web3 应用； 7。有主流 Web3 开源项目贡献经历（Indexer、钱包、区块浏览器、前端 SDK 等）； 8。有 Web3 基础设施公司、交易所或钱包公司工作背景。 我们提供 1。具有竞争力的薪资（45-50K / 月） 2。远程办公，弹性工作时间，以结果为导向 3。扁平化沟通环境，与全球化团队和行业顶尖工程师共事，可独立推动想法落地
