职责描述

  • 使用 Solidity 设计和开发生产环境中的智能合约。
  • 开发和维护基于 EVM 的区块链应用。
  • 编写智能合约的单元测试、集成测试和端到端测试。
  • 负责智能合约代码审查，包括正确性、安全性和 Gas 优化。
  • 参与智能合约架构和技术方案设计。
  • 与后端及前端系统进行智能合约集成。
  • 排查和解决已部署智能合约及区块链系统中的问题。
  • 参与代码 Review，并推动工程开发规范。
  • 与安全团队及外部审计团队合作进行智能合约安全审计。
  • 持续优化链上系统的稳定性和性能。

任职要求

  • 3 年以上软件开发经验，并具有较强的 Solidity 实际开发经验。 熟练掌握 Solidity 和 Ethereum Virtual Machine（EVM）。 有生产环境智能合约开发及部署经验。 熟悉 Ethereum 及常见 EVM 底层机制。 熟悉 Foundry、Hardhat 或其他智能合约开发及测试框架。 了解常见智能合约安全漏洞及防护方式。 熟悉 Git 及标准软件工程开发流程。 了解 Gas 优化和交易执行机制。 能够阅读、理解并维护已有智能合约代码。 有 DeFi、交易所、钱包或其他区块链金融产品开发经验。 熟悉 ERC-20、ERC-721、ERC-1155、ERC-4626 等常见标准。 有可升级合约及合约部署框架经验。 有区块链 Indexing、Event Processing 或 RPC 基础设施经验。 有智能合约安全审计或配合审计的经验。 有 Layer 2 或其他 EVM-compatible Chain 开发经验。 熟悉 Rust、Go 或 TypeScript。 欢迎新加坡候选人。 支持远程办公。 优先考虑 GMT+8 时区候选人。 需要能够与新加坡/APAC 时区团队进行日常协作。
