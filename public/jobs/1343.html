## 地点

职责描述

  • 你将负责：
  • 开发与维护以 Web3 功能为重点的可扩展 Web 应用
  • 构建响应式、用户友好的前端界面
  • 设计与实现后端服务、API 与数据库集成
  • 集成区块链网络、智能合约与 Web3 钱包
  • 优化应用性能、可靠性与安全性
  • 与产品经理、设计师及其他开发者协作
  • 参与代码评审、技术讨论与架构决策
  • 你需要具备
  • 较强的问题解决与分析能力
  • 主动推进开发与持续改进
  • 注重细节，坚持代码质量
  • 能在远程团队中独立工作并协作
  • 对区块链技术与去中心化产品有兴趣
  • 与我们共事的优势
  • 灵活的远程工作环境
  • 协作型团队，提供职业成长空间
  • 接触现代技术与新兴区块链生态
  • 开发去中心化应用与 Web3 平台
  • 将区块链网络与智能合约集成到 Web 应用中
  • 构建安全的钱包认证与交易流程
  • 为区块链产品设计可扩展的后端服务
  • 提升 Web3 应用的性能与可靠性

任职要求

  • 具备全栈、前端或后端软件开发经验 深入理解 Web 应用架构与现代开发实践 具备 Web3、区块链或去中心化应用经验 熟悉区块链集成、智能合约与 Web3 API 了解安全性、性能优化与可扩展系统设计 熟悉 Git 与协作开发流程 技能 必备： 精通 JavaScript 或 TypeScript 熟悉现代前端框架，如 React 或 Next.js 具备 Node.js 或类似技术的后端开发经验 了解 REST API、数据库与应用架构 理解 Web3 技术、钱包与区块链交互 能够编写整洁、可维护且经过良好测试的代码 理想情况： 具备 Solidity 与智能合约开发经验 熟悉 Ethereum、EVM 兼容网络或其他区块链生态 有 ethers.js、viem 或 Web3.js 使用经验 了解 DeFi、NFT、代币化或去中心化应用 有 Docker、云服务与 CI/CD 流水线经验 熟悉智能合约安全与区块链交易流程 有竞争力，根据经验和技能面议
