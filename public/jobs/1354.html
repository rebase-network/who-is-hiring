职位概述

Tervanio — Rust Solana Developer

职责描述

  • 你将负责：
  • 开发与维护基于 Rust/Anchor 的 Solana 链上程序
  • 设计账户结构、PDA、CPI 与链上执行逻辑
  • 将 Solana 程序与后端、前端及 AI Agent 组件集成
  • 优化计算单元、交易大小与执行成本
  • 编写测试、审查自身代码并检查安全性
  • 参与代码评审、技术讨论与架构决策
  • 与产品、后端及前端团队协作
  • 监控链上活动并诊断线上问题
  • 你需要具备
  • 较强的问题解决与分析能力
  • 主动推进开发与持续改进
  • 注重细节，坚持代码质量与安全意识
  • 能在远程团队中独立工作并协作
  • 对 Solana、AI Agent 与去中心化产品有兴趣
  • 与我们共事的优势
  • 灵活的远程工作环境
  • 协作型团队，提供职业成长空间
  • 接触现代 Solana 技术与新兴区块链生态
  • 开发 AI Agent 驱动的 Solana 去中心化应用与 Web3 平台
  • 将 AI Agent 与 Solana 智能合约、链上交易流程集成
  • 构建安全的钱包认证与交易签名流程
  • 为 AI Agent 设计可扩展的链上执行框架
  • 提升 Solana 应用的性能与可靠性

任职要求

  • 具备 4 年以上 Rust 开发经验，其中至少 2 年 Solana 或 Web3 领域经验 深入理解 Solana 账户模型、PDA、CPI、租金、计算单元与交易生命周期 具备 Solana 链上程序开发经验，熟悉 Rust 与 Anchor 了解 SPL Token、Associated Token Account 与 Token Extensions 熟悉 RPC 集成、solana-sdk、solana-client 或 web3.js 了解 Solana 程序安全：signer 检查、owner 检查、账户校验、溢出与重入类风险 具备测试经验：anchor test、solana-program-test、bankrun 或类似工具 了解交易优化、程序大小、计算单元与执行成本 熟悉 Git 与协作开发流程 技能 必备： 精通 Rust：所有权、生命周期、async/tokio、错误处理、trait、泛型 精通 Solana：Anchor、PDA、CPI、SPL Token、账户模型 具备钱包连接、交易签名、链上数据读取经验 了解 REST API、GraphQL 与后端集成 能够编写整洁、可维护且经过良好测试的代码 理想情况： 具备 DeFi、NFT、代币化、质押或 Solana 基础设施项目经验 了解 AI Agent 产品形态、LLM 集成与工具调用 有 Docker、云服务与 CI/CD 流水线经验 了解 Ethereum、EVM 兼容网络或 Solidity 了解 RAG、向量数据库、Prompt Engineering 或 Agent 记忆机制 有代码评审与架构决策经验
